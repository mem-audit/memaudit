# memaudit brand assets

Generated org / product marks for GitHub, Hugging Face, PyPI, Discord, and the marketing site.

## Files

| File | Use |
|------|-----|
| `logo-github.png` / `../marketing/memaudit-logo-github.png` | **GitHub org avatar** — 512×512, optimized PNG, clearly under 1 MB |
| `logo.png` / `logo-avatar.png` / `memaudit-logo.png` | Full-resolution primary mark (cream paper + stamp-red monogram) — use elsewhere when size is not constrained |
| `logo-dark.png` / `memaudit-logo-dark.png` | Dark-bg variant for Discord / dark UIs |
| `logo-wordmark.png` / `memaudit-wordmark.png` | Horizontal lockup (¶ mark + “memaudit”) for headers / decks |

## Recommended use

- **GitHub org avatar:** upload `logo-github.png` (< 1 MB; GitHub rejects uploads over 1 MB). Source is 512×512 (≥500px required). Prefer this over full `logo.png`.
- **Hugging Face / other avatars:** `logo-github.png` is fine; use full `logo.png` if the platform has no size cap and you want maximum detail.
- **Favicon source:** crop/scale the cream mark; site currently uses an inline SVG ¶ favicon.
- **Wordmark:** prefer CSS header wordmark on the landing page; PNG lockup is for slides, README banners, social cards.

## Palette

- Paper cream `#F6F1E7`
- Stamp red `#B23A1D`
- Ink `#191510`
- Dark terminal `#17130D` (dark variant background)
